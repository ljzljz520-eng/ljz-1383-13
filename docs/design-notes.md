# 技能证据图 · 设计决策记录

## D1「规则驱动汇总」vs「只展示证据强度」

| 维度 | 规则驱动汇总（**采用**） | 只展示证据强度（对照，未采用） |
|---|---|---|
| 读者成本 | 低：档位一眼可读 | 高：需自行综合多条证据 |
| 可解释性 | 每条结论可展开为证据+依赖路径+规则编号 | 天然透明，但无结论 |
| 被误读为"认证分数"的风险 | 存在，**用三条纪律规避** | 最低 |
| 版本化升级 | 可在旧规则旁并存新版本、全量重算对比 | 无需升级，也无法对比 |

**决定：采用 rule_driven**，并用以下纪律保证不滑向"客观总分"：

1. **三类信息分列**：主观自评分（1–5，始终标注"主观"）、可验证成果（带链接/到期状态）、计划目标（明确"未完成"）。
2. **只给文字档位**，不给数字总分：`verified_strong / verified / verified_result / at_risk / planned / self_asserted / no_signal`。
3. 每个档位都能下钻到：**是哪些证据、经哪条依赖路径（前置→本节点）、应用了哪个规则版本**。
4. 档位旁固定免责语："按既定规则的自我整理，不是客观认证"。

`evidence_only` 方案作为 `0.9.0-evidence-only` 记录在 `rule_versions` 表与 `/api/meta/policy`，永不删除，便于回溯决策。

## D2 规则版本

- **v1.0.0**（默认激活）：三信息分列；有效可验证成果 → `verified_result`；无成果有计划 → `planned`；仅自评 → `self_asserted`；皆无 → `no_signal`。
- **v2.0.0**（可升级）：引入证据强度（strong=可核验链接 / moderate=无链接 / limited=30 天内临期），
  对应 `verified_strong / verified / at_risk`；弱化原因逐条带依赖路径。
- 每个版本是不可变记录（`rule_versions.spec`），评估结果按 `(node_id, rule_version)` 分别保存，
  因此同节点在两个版本下的结论可同时存在、相互对照。

## D3 多父依赖图与证据去重

- 能力节点允许多父：`edges(parent→child)`，parent 是前置；全图是 DAG。
- 新增边在**串行写临界区**内完成"环检测 + 插入"，杜绝两个并发请求互相通过检查。
- 评估时收集本节点与**全部传递前置**的证据；同一 `evidence_id` 即使挂在多个节点、
  且每个节点有多条路径到达本节点，**只计一次**。展示时为证据选最短依赖路径标注。

## D4 到期 / 撤下传播

- 证据状态 `active/expired/withdrawn`；`valid_to` 到期由定时清扫自动置 `expired`。
- 变更影响集合 = 挂载节点 + 沿正向边的全部后代，入重算作业队列。
- 过期/撤下证据不计入有效数，而以**可定位弱化原因**形式保留：含证据、原因类型、
  依赖路径（`前置 A → … → 本节点`），不使用统一的"证据不足"标签。

## D5 迟到作业

- 作业入队时固化 `rule_version`；到期才执行。
- 若等待期间规则升级，作业到期后仍按**入队时版本**计算，结果与作业行显式标记 `late`，
  并在 `evaluations.recompute_note` 注明"迟到作业"。重算作业不回写新版本下的结论。

## D6 部分证据私密

- `is_public=0` 的证据**照常参与计数、档位、弱化判定**（否则私密设置反而泄露信息强度），
  但公开 API 只返回占位 `{masked:true}`：无标题、URL、类型；只保留数量与依赖路径形态。
- 历史导出快照在**生成时**即以公开视图序列化，私密标题从不写入 `exports` 表。
- 自评与计划的私密项在公开视图整行隐藏。

## D7 历史导出不可变

- 导出冻结全图（节点、边、各节点档位、证据脱敏形态、规则版本），存为不可变 JSON。
- 之后证书到期、作品撤下、节点合并、规则升级都不回改旧快照；新结论请重新导出。

## D8 节点合并

- `source → target`：边重指并去重，重指前对每条候选边做环检测，成环即整笔 409 回滚；
- 证据挂接、自评、计划迁移到 target；source 置 `merged_into`（不物理删除，可追溯）；
- target 及其全部后代入重算队列；访问旧 id 返回 410 与 `mergedInto` 指引。
